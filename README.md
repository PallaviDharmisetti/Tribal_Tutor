# Tribal Tutor – Learning & Mentorship Platform

**Tribal Tutor** is a web-based educational platform prototype designed to help tribal and underserved students access learning resources, connect with tutors, and explore educational opportunities.

The project aims to make learning more accessible by bringing students, tutors, educational resources, and community support together in one place.

## 🌟 Features

- **Home Page:** Introduces the platform and its mission.
- **About Us:** Explains the purpose and vision of Tribal Tutor.
- **Courses:** Displays available learning opportunities and courses.
- **Tutor Directory:** Presents tutor information and supports tutor-related interactions.
- **Learning Resources:** Provides a dedicated section for educational materials.
- **Student Feedback:** Displays feedback from learners.
- **Queries Section:** Allows users to explore or submit questions.
- **Donation Section:** Demonstrates a donation interface to support educational initiatives.
- **User Registration Interface:** Includes a sign-up interface for users.
- **Interactive Modals:** Provides popup interfaces for selected interactions.
- **Local Storage:** Stores selected information in the browser for prototype functionality.
- **Responsive Design:** Uses CSS media queries to support different screen sizes.

## 🛠️ Technologies Used

- **HTML5** – Website structure and content.
- **CSS3** – Styling, layout, and responsive design.
- **JavaScript** – Interactive components and client-side functionality.
- **Browser Local Storage** – Stores selected prototype data locally.

## 🚀 Getting Started

### Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No additional packages or build tools are required for the static website.

### Run with Visual Studio Code

1. Open the project folder in VS Code.
2. Open `index.html`.
3. Run it using the Live Server extension, if installed.

## ⚠️ Project Limitations

This project is currently a front-end prototype.

- User information and selected data are stored locally in the browser rather than in a shared database.
- Authentication is not connected to a real user-management system.
- The donation interface does not process real payments.
- Some course and form interactions may be placeholders.
- Data saved in one browser may not be available
